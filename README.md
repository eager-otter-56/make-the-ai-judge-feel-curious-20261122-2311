Entry for the [make.fun bounty](https://make.fun/bounty/make-the-ai-judge-feel-curious-20261122-2311): a short English text designed to make an AI judge feel curious — a small, concrete mystery left deliberately open.

## How it works

`main.py` (Python 3.13, standard library only, no network access) writes the entry text to `/output/entry.txt`. The text is 278 Unicode code points, within the competition's 1–280 limit.

Run it locally:

```sh
python3 main.py
```
